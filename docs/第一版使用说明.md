# 数学测试台：第一版使用说明

个人逐题测试 Qwen 数学解题的本机应用。固定开启 CoT 思考模式，思考过程默认折叠，可展开查看。不支持 TIR，也不规划 TIR。

## 启动

需要 Node.js 22（当前开发环境为 22.22.1）、可连接的 MongoDB 及到 231:8200 的网络连通性。先在 `.env` 配置数据库连接。

```bash
cd /home/zj/aigc/dep_qwen38-27B
npm ci
npm run db:migrate
npm run dev
```

访问 http://127.0.0.1:5173 。Vite 将 `/api` 请求代理至本机 3100 后端。默认模型地址为 `http://192.168.8.231:8200/v1`，模型名为 `qwen38-27b`。

可按 `.env.example` 在项目根目录创建 `.env`。后端读取 HOST、PORT、MODEL_BASE_URL、MODEL_NAME、MODEL_API_KEY、MODEL_TIMEOUT_MS、IMAGES_DIR 以及下面的 MongoDB 配置。DATASET_PATH、RUNS_DIR 仅供迁移命令读取源数据。默认请求超时 15 分钟；修改后端 PORT 时也需要修改 `vite.config.ts` 的代理目标。环境文件不提交。

MongoDB 使用 `MONGODB_HOST`、`MONGODB_PORT`、`MONGODB_DATABASE`、`MONGODB_USERNAME`、`MONGODB_PASSWORD`。`MONGODB_AUTH_SOURCE` 默认与数据库名相同；只有用户创建在 admin 库时才填写 admin。可选 `MONGODB_URI` 完整连接串优先于其他连接项，仍需配置 `MONGODB_DATABASE` 选择业务数据库。凭据仅在后端使用。

生产形式的本机验证：停止开发服务后运行 `npm run build`，再运行 `npm start`，访问 http://127.0.0.1:3100 。构建后的静态页面和 API 由同一进程提供。当前启动脚本使用 tsx，因此安装时不能省略 devDependencies。

## 使用

侧栏“数学测试台”下方提供“模型 URL”和“模型名称”两个联动下拉框，同一个地址可保存多个模型名称。“管理模型配置”支持新增或编辑 URL/名称，并保存到 MongoDB 的 `model_configs` 集合；选中的配置保存在 `model_settings`，刷新后仍然选中。生成期间不能在当前页面切换模型，后台已经启动的请求使用自己的快照。

`.env` 的 `MODEL_BASE_URL`、`MODEL_NAME` 仅在模型配置集合为空时初始化默认项；以后修改这些环境变量不会覆盖数据库配置，请通过页面管理。URL 应填写 API 基础地址（通常以 `/v1` 结尾），不包含 `/chat/completions`；名称必须与目标服务提供的模型名称一致。目标服务仍需支持当前 CoT 请求格式。`MODEL_API_KEY` 仅用于与环境变量中基础地址相同的配置，不发送给其他地址；暂不提供逐模型密钥管理。

每条新回答保存 `modelBaseUrl`、`modelName`、`modelConfigId`，保留原 `model` 字段兼容旧数据。历史页面显示本次实际使用的 URL/名称，“本次运行参数”也包含两者。配置编辑不会更改旧记录；旧记录没有 URL 的显示“旧记录未保存”，不根据当前配置补填。

1. 在左侧按题号、题干关键词、分类、难度筛选题目。数量动态读取；当前文件名含 275，但实际为 250 题。
2. 点击“开始测试”。每次独立请求，不发送参考答案或其他题目的历史。
3. 等待响应后显示“思考中”；收到正式正文后开始流式展示解答。同一时间只运行一道题，期间可切换题目浏览，所有题目的开始按钮禁用；仅活动题目的停止按钮可用，切回后可继续查看流式结果。
4. 可停止生成，已收到的正文仍会保存。连接断开也会中止上游请求。
5. 展开参考答案对照，人工评价并保存备注。历史中可重新打开旧运行；刷新不会删除记录。
6. 展开“题目原图”或“参考答案原图”，点击图片可在新标签页查看大图。图片仅供页面查看，当前模型请求仍为文字题干，不会自动将原图发送给模型。
7. 题目、模型解答、参考答案均有“复制 Markdown”，复制原始正文（含 LaTeX），不包含思考内容。流式生成中可复制当前已收到的正文。
8. “思考过程”默认折叠，点击后查看模型返回的推理原文；新记录将其独立保存在 MongoDB 的 reasoning 字段。旧记录没有该字段，页面提示未保存，无法补回历史思考。

高级设置支持 temperature、top_p、top_k、max_tokens。默认 1.0 / 0.95 / 20 / 8192，仅作为比较起点。后端固定发送 `chat_template_kwargs.enable_thinking=true`。输出预算包括思考与正文，输入和输出总和不得超过服务的 32768 上下文上限；预算过大时模型接口可能拒绝请求，页面会显示错误。

## 指标与结束状态

首响应时间：后端发起请求到首个非空思考或正文片段。思考阶段耗时：首个思考片段到首个正式正文片段。总耗时：发起请求到完成、失败或取消。

时间基于后端单调时钟，思考阶段是流式观测值，不是 GPU 内部精确计时。页面阶段计数用于实时反馈，结束后使用后端统计。未观察到完整思考阶段时显示未知及原因。生成 tokens 使用接口 usage 数据，缺失时显示未知，绝不把字符估算当成真实 token 用量。

`completed` 为正常完成；`truncated` 表示输出预算耗尽；`cancelled` 为用户取消或客户端断开；`failed` 包括超时、接口异常、空答案或异常断流；`interrupted` 表示应用重启后发现未结束记录。非完成状态不能视为正确答案。

## 数据与公式

运行时以 MongoDB 为唯一数据源：`questions` 集合保存题库和图片相对路径；`runs` 集合保存正式解答、独立的思考原文、题干快照、完整请求（无参考答案和 API 密钥）、参数、统计、人工评价。两者均按 id 建唯一索引，历史另有题号/时间索引。思考与正式答案分别通过 reasoning_delta、answer_delta 返回。流式期间约每 2 秒保存数据库检查点；进程异常退出可能丢失最后一个检查点之后的增量。

`npm run db:migrate` 从原 JSONL 和 `data/runs/*.json` 导入数据，按 ID 仅插入缺失记录。重复运行不会覆盖数据库现有的题干、答案或评价。原文件完整保留作为迁移前备份，新记录不再写入 JSON；启动不再读取原 JSONL。数据库不可用时明确报错，不回退到文件存储。

图片目录继续使用项目根目录的 `images/`，无需移动。默认 `IMAGES_DIR=images`，以后部署可改为挂载目录的绝对路径，数据库中的 `images/文件名.jpg` 不用更改。图片通过题号和类型受控提供，不公开整个目录。检查时共有 940 个文件，其中题库引用的 250 张题目图、111 张参考答案图全部存在；其余文件保留。备份需同时覆盖 MongoDB 和图片目录，图片二进制不放入 MongoDB。

支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 以及 `\boxed{}`，代码块保持原样。原始 HTML 禁用，KaTeX 不开启 trust。题库参考答案来自 OCR，可能存在错误，不能自动当成判分标准。图片缺失时显示路径提示；文字题干缺少图形信息时，当前文字推理结果可能不完整。

## 开发验证

```bash
npm run check
npm test
npm run test:mongodb
npm run build
```

核心测试覆盖 SSE 分片/UTF-8、思考与答案分离、混合片段、usage、取消、截断、断流、公式边界和历史恢复。`node scripts/browser-interactions.mjs` 使用模拟流验证生成期间切题、按钮状态、三个 Markdown 复制按钮、折叠思考、在另一题页面时完成与取消；不会调用模型或写数据库。

`npm test` 不要求真实数据库，MongoDB 集成项默认跳过；`npm run test:mongodb` 使用 `.env` 连接真实数据库，创建随机命名的测试集合，验证幂等导入、评价持久化、未完成记录恢复，结束仅删除这些测试集合，不接触业务集合。图片路径测试覆盖中文文件名、缺失文件和目录越界。

启动开发服务后，可运行 `node scripts/browser-smoke.mjs` 做浏览器渲染检查（首次需要 `npx playwright install chromium`）。设置 `LIVE_SMOKE=1` 后运行同一脚本，会实际调用 231：完成一道题，保存“待复核”评价并验证刷新，再发起一次请求验证取消。这会产生真实历史记录。

2026-09-17 验证：类型检查、7 项核心测试、生产构建通过。浏览器成功渲染题干、参考答案与正式解答，评价刷新后保留，取消生效，无 JavaScript 错误。真实题 MATH-162 正常完成：思考阶段 22.110 秒，总耗时 42.285 秒，386 completion tokens；仅为单次冒烟数据，不代表性能基准。构建目前提示主 JS 包超过 500 kB（包含数学渲染器），不影响使用，按需加载可后续优化。

## 当前限制

MongoDB 接入验收（2026-09-17）：成功导入 250 道题、4 条旧历史，并逐条比对与原文件一致；再次迁移新增 0 条。8 项离线测试和 1 项真实 MongoDB 集成测试、类型检查及构建通过。浏览器验证两类原图、数据库历史和评价刷新保留；真实 CoT 题 MATH-162 完成（思考 19.277 秒，总耗时 41.281 秒），另一次请求验证取消。两条新自测记录仅存 MongoDB，原 4 个 JSON 历史文件保留。

仅单进程、单活动请求，默认仅绑定 127.0.0.1，无账号系统。刷新或离开页面会取消当前流；可以从历史查看已保存结果。不要启动多个共用同一数据库的后端进程：当前启动恢复逻辑假设单实例。批量评测、自动评分、图片输入模型、远程部署均为后续独立任务。当前没有改动 231 模型容器。
