# 数学测试台：第一版使用说明

个人逐题测试 Qwen 数学解题的本机应用。固定开启 CoT 思考模式，不显示、不保存思考原文。不支持 TIR，也不规划 TIR。

## 启动

需要 Node.js 22（当前开发环境为 22.22.1）及到 231:8200 的网络连通性。

```bash
cd /home/zj/aigc/dep_qwen38-27B
npm ci
npm run dev
```

访问 http://127.0.0.1:5173 。Vite 将 `/api` 请求代理至本机 3100 后端。默认模型地址为 `http://192.168.8.231:8200/v1`，模型名为 `qwen38-27b`。

可按 `.env.example` 在项目根目录创建 `.env`。后端读取 HOST、PORT、MODEL_BASE_URL、MODEL_NAME、MODEL_API_KEY、MODEL_TIMEOUT_MS、DATASET_PATH、RUNS_DIR。默认请求超时 15 分钟；修改后端 PORT 时也需要修改 `vite.config.ts` 的代理目标。环境文件不提交。

生产形式的本机验证：停止开发服务后运行 `npm run build`，再运行 `npm start`，访问 http://127.0.0.1:3100 。构建后的静态页面和 API 由同一进程提供。当前启动脚本使用 tsx，因此安装时不能省略 devDependencies。

## 使用

1. 在左侧按题号、题干关键词、分类、难度筛选题目。数量动态读取；当前文件名含 275，但实际为 250 题。
2. 点击“开始测试”。每次独立请求，不发送参考答案或其他题目的历史。
3. 等待响应后显示“思考中”；收到正式正文后开始流式展示解答。运行期间锁定题目切换。
4. 可停止生成，已收到的正文仍会保存。连接断开也会中止上游请求。
5. 展开参考答案对照，人工评价并保存备注。历史中可重新打开旧运行；刷新不会删除记录。

高级设置支持 temperature、top_p、top_k、max_tokens。默认 1.0 / 0.95 / 20 / 8192，仅作为比较起点。后端固定发送 `chat_template_kwargs.enable_thinking=true`。输出预算包括思考与正文，输入和输出总和不得超过服务的 32768 上下文上限；预算过大时模型接口可能拒绝请求，页面会显示错误。

## 指标与结束状态

首响应时间：后端发起请求到首个非空思考或正文片段。思考阶段耗时：首个思考片段到首个正式正文片段。总耗时：发起请求到完成、失败或取消。

时间基于后端单调时钟，思考阶段是流式观测值，不是 GPU 内部精确计时。页面阶段计数用于实时反馈，结束后使用后端统计。未观察到完整思考阶段时显示未知及原因。生成 tokens 使用接口 usage 数据，缺失时显示未知，绝不把字符估算当成真实 token 用量。

`completed` 为正常完成；`truncated` 表示输出预算耗尽；`cancelled` 为用户取消或客户端断开；`failed` 包括超时、接口异常、空答案或异常断流；`interrupted` 表示应用重启后发现未结束记录。非完成状态不能视为正确答案。

## 数据与公式

原题库只读。历史在 `data/runs/<run-id>.json`，通过临时文件 + 原子重命名写入，已加入 Git 忽略规则。保存正式解答、题干快照、完整请求（无参考答案和 API 密钥）、参数、统计、人工评价。思考原文不向前端转发，也不写入记录。流式期间约每 2 秒保存检查点；进程异常退出可能丢失最后一个检查点之后的增量。

支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 以及 `\boxed{}`，代码块保持原样。原始 HTML 禁用，KaTeX 不开启 trust。题库参考答案来自 OCR，可能存在错误，不能自动当成判分标准。当前不提供题库引用的图片；页面显示图片缺失提示，依赖原图的题目需要补齐图片后测试。

## 开发验证

```bash
npm run check
npm test
npm run build
```

核心测试覆盖 SSE 分片/UTF-8、思考过滤、混合片段、usage、取消、截断、断流、公式边界和历史恢复。

启动开发服务后，可运行 `node scripts/browser-smoke.mjs` 做浏览器渲染检查（首次需要 `npx playwright install chromium`）。设置 `LIVE_SMOKE=1` 后运行同一脚本，会实际调用 231：完成一道题，保存“待复核”评价并验证刷新，再发起一次请求验证取消。这会产生真实历史记录。

2026-09-17 验证：类型检查、7 项核心测试、生产构建通过。浏览器成功渲染题干、参考答案与正式解答，评价刷新后保留，取消生效，无 JavaScript 错误。真实题 MATH-162 正常完成：思考阶段 22.110 秒，总耗时 42.285 秒，386 completion tokens；仅为单次冒烟数据，不代表性能基准。构建目前提示主 JS 包超过 500 kB（包含数学渲染器），不影响使用，按需加载可后续优化。

## 当前限制

仅单进程、单活动请求，默认仅绑定 127.0.0.1，无账号系统。刷新或离开页面会取消当前流；可以从历史查看已保存结果。不要启动多个共用同一历史目录的后端进程。批量评测、自动评分、图片服务、远程部署均为后续独立任务。当前没有改动 231 模型容器。

实现参考：[react-markdown 公式插件示例](https://github.com/remarkjs/react-markdown#use-remark-and-rehype-plugins-math)、[Fastify 流式响应](https://fastify.dev/docs/latest/Reference/Reply/#hijack)。
